## 独立 OpenWrt 25.12.0 用户态环境

使用官方 x86/64 rootfs，在 Ubuntu 的独立测试目录中通过 PRoot 执行真实 APK 3.0.2、rpcd、ubusd、uhttpd、LuCI 与 Bootstrap。没有启动额外 VM，没有修改原 OpenWrt 构建目录。

PRoot 不提供完整 OpenWrt 内核/PID 1，因此测试服务额外提供了明确标记的 system.board / system.info 硬件信息替身，并为宿主 UID 添加测试环境的 ubus 传输 ACL。这些文件不属于本插件、不进入交付 APK。包数据、软件源、APK 求解与文件安装/卸载、rpcd 会话及 CGI 文件执行权限都是真实实现。显示的存储容量属于该用户态测试环境所在的宿主磁盘，不能当作目标路由器容量。

已通过：

- 从 LuCI 原生菜单加载 11,000 多个真实包；中文翻译、搜索、分类、排序、分页与包详情。
- `tree` 的真实界面安装和卸载，返回码均为 0，安装数量随之变化。
- 两个不含服务/脚本的签名测试包 `pm-modern-test-a/b`：批量安装 1.0-r1，批量升级至 2.0-r1，再批量卸载，均由界面调用系统 APK 成功完成。临时测试索引与测试签名仅用于测试，不进入插件和生产仓库。
- 只读角色加载原生页面，安装与刷新按钮不可用；真实 CGI 读取成功、写入 403。未登录 CGI 请求 403；带非法 flag 的写入在参数门返回 code=64。
- 相关的 10 项服务端权限结果见 `acl-results.json`。
- Bootstrap 深浅模式桌面与 390px 窄视口；浮动队列入口与跳转；Argon 3.1.0 深浅模式桌面。最终恢复为 Bootstrap Light。

## 尚未验证 / 已知限制

- 未在 ARM/MIPS 设备或真实硬件路由器部署；未进行固件整编、硬件断电、极低内存与磁盘耗尽测试。

- 失败组内可能部分完成；没有事务回滚。页面队列与日志不跨刷新恢复，也没有后台任务恢复接口。
- 仓库状态只报告缓存信息与当前会话刷新结果，不承诺所有源可达。第三方源可独立超时或变更。
- 开发 APK 未由用户生产固件密钥签名；生产集成须用用户自己的发布流水线。
